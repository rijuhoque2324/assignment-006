# FITLOG — Workout Library

FITLOG is a modern workout library and fitness planning web application built with Next.js. Users can browse different workouts, view detailed workout information, add exercises to today's plan, save workouts for later, and manage their workout plan through a clean and responsive interface.

## Technologies Used

| Technology | Purpose |

| Next.js | Build the user interface and application |
| Next.js App Router | Handle page navigation and dynamic routes |
| TypeScript | Provide type safety and improve code reliability |
| Tailwind CSS | Styling and responsive design |
| DaisyUI | Reusable UI components and theme support |
| React Context API | Manage shared workout plan and saved workout state |
| React Toastify | Display success and notification messages |
| Lucide React | Icons used throughout the application |

## Key Features

### 1. Workout Library
Users can browse a collection of workouts with useful information such as muscle groups, duration, calories burned, and ratings.

### 2. Workout Details
Each workout has a dedicated details page containing:

- Workout description
- Muscle groups
- Equipment
- Difficulty level
- Sets and reps
- Duration
- Calories burned
- Rating
- Exercise instructions

### 3. Today's Workout Plan
Users can add workouts to their daily plan. The plan automatically displays the total number of exercises, total workout duration, and total calories.

### 4. Save Workouts for Later
Users can save workouts they are interested in and access them from the Saved section of the My Plan page.

### 5. Workout Plan Management
Users can manage their workouts by:

- Removing workouts from the plan
- Removing saved workouts
- Marking workouts as done
- Sorting workouts by duration, calories, or rating
- Switching between Today's Plan and Saved workouts
